# JSON 工程文件

完成转换后，结果页提供 Save GIF 和 Save Project 两个独立保存入口。Save Project 默认保存为 `视频名.gifski.json`。重新打开相同视频，在编辑页工具栏点击 Import Project，选择 JSON 即可恢复。成功导入会替换当前视频的编辑配置；校验失败则保留当前编辑内容。

工程保存原视频文件名、SHA-256 和 metadata（尺寸、时长、帧率、文件大小、音轨状态、方向变换），以及速度、源时间轴与变速后时间轴的起止秒数、精确输出尺寸、FPS、Quality、循环、往返播放、循环延迟、归一化裁剪矩形、所有文字图层（含字体、位置、字号、描边、颜色、对齐、宽度）。不包含视频或 GIF 图像数据。

视频以内容识别，改名或移动文件不会破坏关联。工程还记录格式版本、渲染版本、应用/macOS 版本、实际字体文件指纹及已完成 GIF 的 SHA-256。视频不匹配、缺失或变化字体、未知版本、不兼容渲染环境和非法参数会被拒绝。恢复后配置未改变时，重新编码会验证 GIF 的完整字节校验值，若不一致则报错，不将不同文件当成成功重现。更改配置后导出将产生新的工程和校验值。

导入不要求视频原路径相同。不承诺跨 macOS 或字体版本生成相同字节；这种情况会明确拒绝复现。工程本身为可读 JSON，但手工修改参数会改变结果，也可能无法通过验证。
